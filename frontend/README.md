# Frontend — Controle de Finanças

Frontend React + Vite da aplicação.

## Desenvolvimento

```bash
npm install
npm run dev
```

A API é acessada em `http://localhost:3000/api` por padrão. Use
`VITE_API_URL` em um `.env` local para alterar o endereço.

## Verificações

```bash
npm run lint
npm run build
```

As Fases 1 e 2 incluem cadastro, login, restauração de sessão, logout, contas,
categorias e subcategorias. As telas são Mobile First e a navegação inferior é
exibida em celulares. O dashboard financeiro será implementado na Fase 6.
